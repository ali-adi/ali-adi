I'm Muhammad Aditya Alifadhilah (Ali), an AI engineer at [Medicoder](https://medicoder.io) in Singapore. Before that I did research on federated learning, machine unlearning and medical AI at NTU, A\*STAR and the Digital Trust Centre.

## Right now

At Medicoder I work on the extraction pipeline behind Medicoder Studio, our clinical coding assistant. It reads a clinical note and walks the code hierarchy with Gemini to pick ICD-10-AM/ACHI or ICD-10-CM/PCS codes, served through a FastAPI backend.

Outside work I'm building tools for running several coding agents at once, since most of my day is spent next to Claude Code and Cursor.
